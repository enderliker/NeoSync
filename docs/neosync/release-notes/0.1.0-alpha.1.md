# NeoSync 0.1.0-alpha.1 — NeoForge 21.1.251

First experimental installer release of NeoSync's installation MVP. Players can
review a server's required mods, accept verified downloads, prepare an isolated
profile, and manually restart to join.

**This is an alpha prerelease for testing, not a stable compatibility release.**

| Component | Version |
| --- | --- |
| Minecraft Java Edition | 1.21.1 |
| NeoSync | 0.1.0-alpha.1 |
| NeoForge base | 21.1.251 |
| Synchronization protocol | 1 |
| Required Java | 21 |

## Download and install

Download **`NeoSync-0.1.0-alpha.1-neoforge-21.1.251-installer.jar`** for either
the client or the dedicated server. The same installer supports both and embeds
NeoSync's runtime. Client and server must use matching NeoSync and base versions.

For a client, launch the installer with Java 21, choose **Install client**, and
select your Minecraft installation directory. Then select the generated
`NeoSync-0.1.0-alpha.1-neoforge-21.1.251` version in your launcher.

For a dedicated server, create a separate test directory and run:

```sh
java -jar NeoSync-0.1.0-alpha.1-neoforge-21.1.251-installer.jar --install-server /path/to/server
```

Use the generated `run.sh` or `run.bat`, and review and accept the Minecraft EULA
yourself if you agree. The installer downloads Minecraft and standard libraries;
it does not bundle Minecraft game JARs, a world, or third-party mods.

Administrators must explicitly configure the HTTPS manifest service and client
artifact sources. Follow the
[installation guide](https://github.com/enderliker/NeoSync/blob/NeoSync-0.1.0-alpha.1-neoforge-21.1.251/docs/neosync/releases.md)
and [synchronization setup](https://github.com/enderliker/NeoSync/blob/NeoSync-0.1.0-alpha.1-neoforge-21.1.251/docs/neosync/phase-3.md#server-configuration-and-manual-activation).

The `-universal.jar` is a runtime artifact for tooling and inspection, not a
standalone server or a mod to place in `mods`. The `-sources.jar` contains runtime
sources without Minecraft sources. `SHA256SUMS` and `release-manifest.json` record
artifact integrity and the source commit. Full repository sources are available
through GitHub's tag archives. No Maven publication or mod-development kit is
included in this release.

## Validation

- Formatting and all **187 unit tests passed**, with zero failures, errors, or skips.
- The exact installer passed client and dedicated-server installation and startup
  tests on Linux with JDK 21.0.2.
- A fresh graphical run passed review and warning cancellation, HTTPS download,
  verification, isolated preparation, relaunch, and a real server join with
  **Clumps 19.0.0.1**. The test used a loopback server and synthetic test identity.
- Reinstallation preserved an existing launcher-profile entry and sentinel files
  in ordinary NeoForge version/library paths.
- Release archives, version identities, embedded runtime, and checksums were
  inspected. The release-build workflow passed `actionlint`; these results are
  local validation, not a claim that remote CI ran.

## Known limits

- Manual launcher activation and restart are required. No external launcher is
  certified; Windows and macOS runtime validation remains outstanding.
- Only explicitly configured direct HTTPS sources are supported. Automatic
  Modrinth/CurseForge resolution, browser-assisted manual imports, server hosting,
  and automatic restart are not implemented.
- The MVP supports a limited set of JAR arrangements. Nested/library-only or
  alternate-loader artifacts, query-bearing source URLs, and redirects to a
  different origin remain unsupported.
- Hash verification does not establish that a mod is trustworthy. Profile
  isolation is not a sandbox, and startup checks run after FML loads mods.
- Broader modpack, public proxy/SRV, power-loss, and spoken-narration validation
  remain outstanding. See the
  [validation record](https://github.com/enderliker/NeoSync/blob/NeoSync-0.1.0-alpha.1-neoforge-21.1.251/docs/neosync/phase-3.md).
