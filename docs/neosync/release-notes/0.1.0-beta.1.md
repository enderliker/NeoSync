# NeoSync 0.1.0-beta.1 — local candidate

Minecraft **1.21.1**, NeoForge **21.1.251**, Java **21**, synchronization protocol
**1**. This candidate has not been published. If published, it must remain a
prerelease with an immutable versioned tag and matching artifacts.

Administrators can select the mods their clients receive at
`https://MACHINE-IP:6742`. The dedicated server generates a private password in
`config/neosync-admin/password.txt` and a local TLS identity. Verify its
fingerprint before signing in. Saved selections take effect after server restart.
See [administration](../administration.md).

Modrinth is now the only provider. CurseForge lookup and browser import have been
removed. Unsupported old provider profiles are left intact and require a new
revision using a supported source. Explicit direct HTTPS downloads and restricted
hosting for the administrator's own unpublished server-specific mods remain.

Prism integration prepares a separate instance for each accepted revision,
verifies it before mod loading and offers **Close and launch**. Other launchers
retain manual activation. The title-screen **NeoSync profiles** browser can verify
and select a previous revision. Updates preserve removed and replaced mods in the
older revisions; the download cache now has a bounded eviction policy.

Linux acceptance covers live Modrinth installation, Prism restart/reconnect,
Clumps/Ferrite Core combinations, removal and replacement, verified recovery,
restricted hosting, declined consent, process interruption and a real low-space
filesystem. Administrator browser checks cover authentication, selection,
default-negative hosting declarations, HTML injection and desktop/mobile layouts.
The [Phase 7 matrix](../phase-7.md) records exact evidence and limits.

SKlauncher and Minecraft Launcher have documented installed-version/manual-directory
instructions; their GUIs were not runtime-certified. Windows/macOS, broad modpack
compatibility and public SRV/proxy deployments remain untested. Isolation is not
a sandbox, and a provider or matching hash is not a guarantee that code is safe.

Use the same `NeoSync-0.1.0-beta.1-neoforge-21.1.251-installer.jar` for clients and
servers. Local exports include matching universal, sources, earlydisplay and
earlydisplay-sources archives, `SHA256SUMS`, and `release-manifest.json` with the
source commit. No generated Minecraft JARs, worlds, test mods or credentials are
included. See the [release guide](../releases.md).
