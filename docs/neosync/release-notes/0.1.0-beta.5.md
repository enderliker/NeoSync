# NeoSync 0.1.0-beta.5

Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**. Synchronization
capability protocol 1 uses HTTPS and protocol 2 uses explicitly selected HTTP;
the manifest schema remains version 1. Install matching NeoSync versions on the
client and server.

## Changes since beta.4

- The administrator panel accepts a literal public IPv4 address when NAT forwards
  it to a different local address. Named hosts remain rejected. Changes still
  require a matching browser origin, authenticated session, and CSRF token.
- The first dedicated-server start creates `config/neosync-server.json` with
  synchronization disabled and HTTPS defaults. An existing configuration is
  preserved byte for byte.
- `adminPort` in that JSON file selects the administrator panel's listener port.
  It defaults to 6742 and must differ from an enabled manifest listener port.

The [administrator guide](../administration.md) explains the generated file,
custom port, and HTTP/HTTPS settings. For example, set `"adminPort": 7654`,
restart the server, and open `http://MACHINE-IP:7654/` if `adminTransport` is
`"http"`. Allow or forward TCP 7654 to that same server port.

## Installation

Download the installer for both clients and dedicated servers. Existing
installations do not update themselves.

```sh
java -jar NeoSync-0.1.0-beta.5-neoforge-21.1.252-installer.jar
```

For a new dedicated-server directory:

```sh
java -jar NeoSync-0.1.0-beta.5-neoforge-21.1.252-installer.jar --install-server ./neosync-server
```

## Validation and limits

Publication requires successful Linux and Windows GitHub Actions builds on the
release source commit, plus client and dedicated-server installation and startup
from the release installer. The release page records the exact run links and
attached SHA-256 checksums.

The public-address test simulates NAT by sending a public IPv4 Host header to a
service reached through loopback. It covers HTTP and HTTPS, matching login
origins, rejected named hosts, and preserved CSRF protection. This is not a live
cloud NAT or installed HTTP multiplayer acceptance result. Windows graphical
panel interaction and macOS remain unvalidated.

HTTP remains unencrypted and exposes panel credentials in transit when selected.
The generated HTTPS certificate may not include a public address forwarded
through NAT; browser TLS validation still requires a matching certificate.
Beta.4 assets and tags remain unchanged.

## Artifacts

The prerelease includes installer, universal, sources, earlydisplay, matching
earlydisplay-sources JARs, `SHA256SUMS`, and `release-manifest.json`. Generated
Minecraft JARs, installations, test fixtures, worlds, accounts, and credentials
are excluded.
