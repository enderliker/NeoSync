# NeoSync 0.1.0-beta.3

Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**, synchronization protocol
**1**. This is an upstream maintenance prerelease. Install matching NeoSync and
NeoForge versions on the client and server.

## Changes since beta.2

- Updated the NeoForge base from 21.1.251 to 21.1.252.
- Imported upstream [#3469](https://github.com/neoforged/NeoForge/pull/3469),
  commit [`61045a61`](https://github.com/neoforged/NeoForge/commit/61045a61fca76876999281676a9e794688390a9e),
  by sciwhiz12 and Shadows_of_Fire. `StackCopySlot` now accepts the backing slot
  index, and both `ItemHandlerCopySlot` constructors provide it. The previous
  two-argument constructor remains available, deprecated, with index zero.
- Added three regression cases covering backing indices distinct from menu
  indices, writes to the selected slot, and the legacy constructor.

Modrinth remains the only provider. Direct HTTPS sources, restricted hosting,
the administrator panel, isolated profiles, recovery, Prism integration and
beta.2 branding are retained.

## Installation

Download the **installer** for either a client or dedicated server. Install and
select the new version; existing installations do not update themselves. Update
both sides because discovery requires matching NeoSync and NeoForge versions.

```sh
java -jar NeoSync-0.1.0-beta.3-neoforge-21.1.252-installer.jar
```

For a dedicated server in a new directory:

```sh
java -jar NeoSync-0.1.0-beta.3-neoforge-21.1.252-installer.jar --install-server ./neosync-server
```

See [launcher guidance](../launchers.md), [administration](../administration.md),
and the [release guide](../releases.md).

## Validation and limits

Publication is gated on successful **Linux and Windows GitHub Actions runs on
the tagged source commit**. Both workflows build the project, check formatting
and run unit tests with Java 21. Windows also installs and starts the dedicated
server. The GitHub release records links to those exact runs.

The exact release installer is additionally checked on Linux with OpenJDK 21.0.2
using fresh client and dedicated-server installations. Archive validation checks
embedded libraries, versioned paths, matching sources, graphics, upstream notices
and unchanged FML code. The release includes checksums and its source commit.

These checks cover compilation, **239 unit tests**, packaging and startup. They
do not establish Windows graphical-client or launcher GUI compatibility, macOS
support, or a new multiplayer/mod synchronization acceptance run. The broader
gameplay and Prism evidence remains in the [beta.1 Phase 7 matrix](../phase-7.md).
Profile isolation is not a sandbox; hashes do not establish that mod code is safe.

## Artifacts

The release includes installer, universal, sources, earlydisplay and matching
earlydisplay-sources JARs, plus `SHA256SUMS` and `release-manifest.json` identifying
the source commit. Generated Minecraft JARs, installations, test fixtures, worlds,
accounts and credentials are excluded. Earlier release tags and binaries remain
unchanged.
