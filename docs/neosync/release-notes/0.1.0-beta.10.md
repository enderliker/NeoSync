# NeoSync 0.1.0-beta.10

Minecraft **1.21.1**, NeoForge **21.1.256**, Java **21**.

Beta.10 includes beta.9's general NeoForge inventory discovery correction,
`mods_client` support, and default-enabled discovery for new server
configurations. Published beta.8 and beta.9 assets and tags retain their original
bytes and identity.

Prepared SKlauncher 4 instances now live directly under SKlauncher's `instances`
directory. NeoSync copies the reviewed server profile into that sibling instance
and registers it after both Minecraft and SKlauncher have exited, preserving
launcher changes saved while the game ran. Modrinth instance preparation keeps
its existing behavior.

The launcher correction passed Linux and Windows CI, including launcher and
profile tests. The release workflow validates the exact Linux installer on a
client and dedicated server, checks the packaged artifacts, and verifies the
Windows installer wrapper. Native SKlauncher gameplay with this release has not
been independently certified; users still select the NeoSync instance and press
Play in SKlauncher.
