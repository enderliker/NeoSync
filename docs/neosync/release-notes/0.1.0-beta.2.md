# NeoSync 0.1.0-beta.2

Minecraft **1.21.1**, NeoForge **21.1.251**, Java **21**, synchronization protocol
**1**. This is a branding and maintenance prerelease; use matching NeoSync
versions on the client and server.

## Changes since beta.1

- New interlocking symbol with a white N between black elements. Launcher and
  README icons have no enclosing tile or internal padding.
- Updated client startup graphics, mod-list banner, installer graphics, and
  documentation previews. The installer includes the updated startup library.
- Completed contribution and security guidance, issue forms, pull request
  template, release history, and README installation instructions.
- Fixed full assembly in the standalone fork by packaging its curated changelog
  instead of depending on upstream Git tags.
- Added pinned Linux and Windows CI. Windows checks include assembly, formatting,
  unit tests, and installed dedicated-server startup.

Modrinth remains the only provider. Direct HTTPS downloads and restricted hosting
of administrator-authored, unpublished server-specific mods remain available.
The administrator panel, isolated profiles, verified recovery, and Prism restart
behavior are unchanged from beta.1.

## Installation

Download the **installer** for either a client or dedicated server. Install it as
a new version; existing beta.1 installations retain their original graphics.
Select beta.2 in the launcher after installation. Existing Prism instances retain
their installed component until updated or recreated for beta.2.

```sh
java -jar NeoSync-0.1.0-beta.2-neoforge-21.1.251-installer.jar
```

For a dedicated server in a new directory:

```sh
java -jar NeoSync-0.1.0-beta.2-neoforge-21.1.251-installer.jar --install-server ./neosync-server
```

See [launcher guidance](../launchers.md), [administration](../administration.md),
and the [release guide](../releases.md).

## Validation and limits

On Linux with JDK 21.0.2, formatting and all **236 unit tests** passed with no
failures, errors, or skips. Archive inspection verifies the exact bundled
graphics, versioned installation paths, matching sources and notices, and
unchanged non-graphics FML contents.

The exact installer passed fresh dedicated-server and graphical-client
installation and startup using the production harness. Previous installations
were preserved in separate directories. A subsequent graphical run confirmed
beta.2 at runtime, compared the loaded mod-list banner and startup-module image
against the source PNGs byte for byte, and selected NeoSync in the mod list.
The title screen and displayed banner were visually reviewed:

- [Installed beta.2 title screen](../../assets/neosync-beta2-title.png)
- [New logo in the installed client's mod list](../../assets/neosync-beta2-mod-list.png)

Checks used JDK 21.0.2 on Linux with NVIDIA OpenGL 4.6. The temporary visual
driver captured Minecraft's framebuffer only and is not part of the release.
This confirms installed branding; it does not certify an external launcher's GUI.

The broader synchronization and Prism acceptance evidence belongs to beta.1;
see the [Phase 7 matrix](../phase-7.md). Those gameplay scenarios are not claimed
as new beta.2 runs. Windows CI is configured, but GitHub's account billing lock
prevented the runners from starting. Windows/macOS and external-launcher GUI
compatibility are not newly certified by this prerelease. Profile isolation is
not a sandbox, and matching hashes do not establish that mod code is safe.
