# NeoSync 0.1.0-beta.4

Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**. HTTPS discovery uses
capability protocol **1**; explicitly selected HTTP discovery uses capability
protocol **2**. The manifest schema remains version 1. Install matching NeoSync
and NeoForge versions on the client and server.

## Changes since beta.3

- Added independent HTTP or HTTPS selection for player synchronization and the
  administrator panel. Both default to HTTPS. The panel saves these settings for
  the next dedicated-server start.
- HTTP discovery asks for explicit, default-negative consent before fetching the
  manifest. HTTPS failures never fall back to HTTP. Installation and unverified
  source consent remain separate decisions.
- HTTP server-hosted downloads retain size and hash verification. External and
  Modrinth downloads continue to require HTTPS. HTTP profiles record their
  transport separately; existing HTTPS profiles remain readable.
- Updated the administrator panel with NeoSync's geometric N, monochrome colors,
  responsive layout, and clear notices when HTTP is selected.

## Installation and configuration

Download the **installer** for either a client or dedicated server. Install and
select the new version; existing installations do not update themselves.

```sh
java -jar NeoSync-0.1.0-beta.4-neoforge-21.1.252-installer.jar
```

For a new dedicated-server directory:

```sh
java -jar NeoSync-0.1.0-beta.4-neoforge-21.1.252-installer.jar --install-server ./neosync-server
```

The [administrator guide](../administration.md#http-and-https-settings) explains
the panel controls, ports, and equivalent JSON settings. HTTP has no transport
encryption or server authentication. An HTTP administrator panel exposes its
password and session to network observers. See [launcher guidance](../launchers.md)
for client installation and profile activation.

## Validation and limits

Publication requires successful **Linux and Windows GitHub Actions runs on the
release source commit**. Both workflows build the project, check formatting, and
run unit tests with Java 21. Windows also installs and starts a dedicated server.
The GitHub release records the exact run links.

Before publication, local Linux checks passed **244 JUnit tests**, formatting,
installer and source builds, and archive validation. An isolated Chromium fixture
exercised login, logout, transport settings, inventory filtering, and hosting
declarations over HTTP and HTTPS at desktop and mobile widths. This fixture used
synthetic inventory and generated credentials.

These checks do not establish a new installed HTTP multiplayer flow, Windows
graphical-client or panel behavior, external-launcher compatibility, or macOS
support. Prior installed gameplay and Prism evidence remains in the
[Phase 7 matrix](../phase-7.md). Profile isolation is not a sandbox, and matching
hashes do not establish that mod code is safe.

## Artifacts

The release includes installer, universal, sources, earlydisplay, and matching
earlydisplay-sources JARs, plus `SHA256SUMS` and `release-manifest.json` with the
source commit. Generated Minecraft JARs, installations, test fixtures, worlds,
accounts, and credentials are excluded. Earlier release tags and binaries remain
unchanged.
